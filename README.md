# realtime-app

광주하남영재교육원 중학 융합과정에서 쓰는 **실시간 동시접속 수업앱** 모음입니다.
24명이 한꺼번에 들어와 같은 순간에 시작하고, 기록이 남아야 하는 활동들이 들어갑니다.

- 화면은 **GitHub Pages** 가 CDN 으로 바로 내보냅니다
- 기록은 **Supabase(Postgres)** 에 남습니다
- 배포는 `main` 에 밀어 넣으면 끝입니다

## 첫째 규칙 — 서버가 없어도 수업은 굴러간다

게임 로직은 전부 브라우저 안에서 돕니다. 서버는 **기록과 순위판에만** 쓰입니다.

- 쓰기는 `localStorage` 큐에 쌓였다가 틈틈이 나갑니다. 못 보내면 남아 있다가 나중에 갑니다
- 읽기는 실패하면 «순위 없음»이 될 뿐입니다
- 학교망이 `supabase.co` 를 막아도 **활동 자체는 끝까지 진행됩니다**

라이브러리를 쓰지 않고 `fetch` 만 씁니다. CDN 하나가 막혀서 수업이 날아가는 일을 막기 위해서입니다.

## 구조

```
index.html          활동 목록 + 연결 점검
shared/db.js        데이터 계층 (큐 · 재전송 · RPC)
shared/config.js    Supabase URL 과 anon 키
apps/               활동별 폴더
```

## 여기 들어가면 안 되는 것

이 레포는 **공개**입니다.

- `service_role` 키 — 절대 안 됩니다
- 선생님 코드 — 서버(Postgres 함수) 안에만 둡니다
- 학습지 · 정답지 · 학생 이름 — 비공개 레포에 둡니다

`SUPABASE_URL` 과 anon 키는 원래 브라우저로 나가는 공개 값이라 들어와도 됩니다.
대신 그 키로는 표에 직접 못 씁니다. 쓰기는 전부 함수를 지나갑니다.
